# Pricing sources

Sources observed on November 25, 2026. The observation date is recorded separately from effective dates. The reference has no verified historical start date for the checked standard rates.

- OpenAI lists GPT-5.3-Codex standard input, cached input and output at USD 1.75, 0.175 and 14 per million. GPT-6.2 Sol short-context standard rates are 2, 0.10 and 10. [API pricing](https://developers.openai.com/api/docs/pricing)
- GPT-6.2 Sol applies long-context input/cache rates at 2× and output at 1.5× to the full request when input exceeds 272,000. The threshold itself uses short-context pricing. Fast is 2× Standard and Batch is 0.5×. Ultrafast is 3× through February 28, 2027 and 6× from March 1 Pacific time. [GPT-6.2 Sol pricing and model ID](https://developers.openai.com/api/docs/models/gpt-6.2-sol)
- GPT-5.4 documentation describes a greater-than-272K threshold with session scope. Existing legacy pricing chooses by individual request and uses inclusive legacy rows. These semantics need a dedicated historical and session-level audit. [GPT-5.4 model](https://developers.openai.com/api/docs/models/gpt-5.4)
- Cached reads are included in input and reasoning is included in output. For APIs that expose cache writes, ordinary input is total input less cache reads and writes. The 30-minute and 12-hour write counts are disjoint. The audited reference estimates input, cached reads and output. It requires additional inputs to model write charges. [Usage accounting](https://developers.openai.com/api/docs/guides/agents-api/observability) · [Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching)
- Model snapshots and aliases can differ. The legacy estimator splits date suffixes and uses an eligible rate row. This does not establish which snapshot served the request or when the commercial rate changed. Promotional pricing, region, background processing and separate tool rates require additional conditions. [API pricing](https://developers.openai.com/api/docs/pricing)
- Signed-in Codex usage and Platform API billing have different entitlements. An API-equivalent estimate cannot establish subscription usage, credits used, or increments on a financial statement. [ChatGPT API credits and Codex limits](https://developers.openai.com/api/docs/guides/chatgpt-api-credits) · [ChatGPT rate card](https://help.openai.com/en/articles/20001415)
- OpenAI's source and protocol distinguish cumulative `total_token_usage` from latest `last_token_usage`. Latest counts can also drive active context displays, so the surrounding event matters. [Codex token display source](https://github.com/openai/codex/blob/main/codex-rs/tui/src/token_usage.rs) · [OpenAI token accounting notes](https://github.com/openai/symphony/blob/main/elixir/docs/token_accounting.md)
- Official daily project spending requires the organization Costs endpoint. [Costs API](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs)
